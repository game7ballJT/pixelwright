Pixelwright portable mode

While this file sits next to pixelwright.exe, Pixelwright keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PixelwrightData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Pixelwright with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Pixelwright) instead.
If PixelwrightData can't be written (for example on a read-only drive), Pixelwright says so and
uses %APPDATA%\Pixelwright instead.
